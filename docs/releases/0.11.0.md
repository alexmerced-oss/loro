# Loro 0.11.0

Loro `0.11.0` adds experimental Open Agent Profile (OAP) v1 named agents while preserving the
0.10 stable-core boundary. The implementation provides provisional Level 2 behavior against the
repository's supplied implementation guide. Formal upstream certification remains pending because
the canonical schema repository and conformance fixtures were not available to pin for this release.

## Highlights

- YAML, JSON, and Markdown profile loading with safe YAML timestamps, bounded files, deterministic
  whole-profile and authority-stable spec digests, and root-derived trust.
- Managed, user, and project discovery with within-root collision errors, explicit cross-root
  precedence, shadow reporting, and symlink escape rejection.
- Immutable resolved/effective profile boundaries with fail-closed permission, workspace, tool,
  model, runtime-budget, and writeback narrowing plus explainable adjustments.
- `loro run --agent` and `loro plan --agent` with profile identity in durable sessions, filtered
  native and textual tools, profile role/context assembly, and delimited untrusted state.
- Explicit `@agent-state` learning: pending digest-bound proposals by default or atomic `/state`-only
  writeback when both profile and managed configuration allow `auto`.
- Locked revision checks, spec-digest conflict detection, secret redaction, durable file and parent
  directory fsync, revision history, and audit events for profile lifecycle decisions.
- A complete `loro agents` command group and `loro setup agents` wizard.

## Compatibility And Limitations

Existing configurations and sessions remain readable because the new fields are additive with
safe defaults. Invocations without `--agent` preserve the prior runtime path. OAP remains
experimental and does not join the stable 1.0 promise. `extends`, profile-selected MCP/Skills,
subagents, external profile memory stores, graph references, and formal upstream fixture
certification are deferred.

## Upgrade And Verification

```bash
python -m pip install --upgrade loro-agent==0.11.0
loro --version
loro agents create reviewer --instructions "Review changes and cite concrete evidence."
loro agents validate .loro/agents/reviewer.agent.yaml
loro agents explain reviewer
loro run --agent reviewer "Review README.md"
```

Profile state cannot grant authority. Use `@agent-state TEXT` only for an explicit user-authored
state proposal, inspect it with `loro agents proposals`, and approve it with `loro agents review`.
