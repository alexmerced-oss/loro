# Loro 0.9.0

Loro `0.9.0` is the release-candidate line for controlled enterprise evaluation. It freezes the
repository-owned public contract and adds an installed-deployment readiness report without
claiming that an adopting organization has completed its pilot or assurance gates.

## Highlights

- Added `docs/release-contract.json`, a generated snapshot of every CLI command, persisted schema,
  advertised protocol, supported/experimental surface, support-matrix digest, and reference
  deployment digest.
- Added a CI drift gate. Any contract change must be deliberately regenerated and reviewed.
- Added `loro operations release-readiness`, a content-free installed-environment report covering
  contract version, configuration, identity, sandbox, audit, provider request construction,
  shared-memory status, and external gates.
- Added release-candidate, pilot closure, independent assurance, consumer verification, severity,
  vulnerability, and sign-off procedures.
- Added the frozen contract and readiness report to protected release evidence and checksums.

## Compatibility Freeze

Configuration, audit, metrics, approval, benchmark, and recovery schemas remain `1.0`; Postgres
memory remains schema version `2`; AGS remains `1.0`; and MCP revisions remain `2026-07-28`,
`2025-11-25`, and compatibility-only `2024-11-05`. Python 3.11 through 3.14 and Linux remain the
supported runtime boundary. No surface is deprecated in this release.

## Upgrade And Verification

Follow the `0.8` backup, audit-drain, managed-policy, and isolated-environment procedure. After
installing `0.9.0`, run:

```bash
loro config check --strict
loro doctor
loro operations benchmark --strict --output loro-benchmark.json
loro operations release-readiness
```

`release-readiness --strict` also treats warnings as blocking. A successful local report does not
close its listed external gates.

## External Gates

Controlled pilot completion, accountable ownership, corporate identity/policy validation,
production recovery and outage exercises, independent penetration testing, provider/audit/chat
evidence, and security/privacy/legal/data/operations/product/release approval remain external.
This release is a candidate for those evaluations, not evidence that they occurred.
