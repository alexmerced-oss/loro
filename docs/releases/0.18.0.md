# Loro 0.18.0

Released on 2026-08-29.

This release closes the principal desktop-workspace gaps around Loro's governed runtime without
turning the Web UI into an authority boundary or general-purpose IDE.

- Adds workspace file context, bounded uploads, authenticated artifact previews/downloads, and
  read-only staged/unstaged Git review.
- Adds a unified run center across conversations and AGS graphs, usage and approval visibility,
  opt-in completion notifications, and persistent governed graph schedules.
- Adds sequential, parallel, and coordinator group modes with independently queued approvals.
- Adds an effective MCP, protocol-extension, and skill inventory with no credential disclosure.
- Adds adjacent-project discovery and copyable project-specific launch commands while retaining
  one isolated workspace and policy root per server.
- Expands schema migration, confinement, scheduling, group execution, API, React, bundle, and
  release validation.
