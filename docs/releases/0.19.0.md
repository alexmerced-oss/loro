# Loro 0.19.0

Loro 0.19.0 adds governed prompt-driven OAP profile authoring, universal profile discovery through
`~/.agentprofiles`, and a packaged alexmerced.app WebMCP bridge. Generated profiles are proposals
until reviewed unless local policy explicitly permits activation, and they pass the same schema,
secret, dependency, authority, and atomic-write boundary as manually authored profiles.

The Web UI now preserves graph drafts and live execution state across navigation, reports bounded
planning and run activity, exposes editable card capabilities, improves provider onboarding and
errors, and supplies reviewed lifecycle controls for profiles, skills, plugins, MCP servers, and
related extensions.

The release is validated by the Python and React suites, production asset build, release-contract
verification, package/Twine checks, and installed-wheel smoke tests.
