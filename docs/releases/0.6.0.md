# Loro 0.6.0

Loro 0.6.0 completes the repository-owned Data and Operations milestone on the road to 1.0.
It makes shared-memory storage, audit collection, observability, and recovery substantially
more operable while keeping production governance claims tied to external evidence.

## Highlights

- Versioned, checksummed Postgres migrations with advisory locking, forward/rollback plans, and
  explicit authorization for destructive changes.
- Tenant-scoped operation IDs make draft commits and memory lifecycle retries idempotent; state
  and append-only event reconciliation detects drift.
- Expanded ephemeral Postgres coverage for lifecycle operations, concurrent writers, forced RLS,
  schema drift, migration rollback/forward, and two-database backup/restore.
- A machine-readable reference matrix pins Postgres 16, Apache Polaris 1.6.0, Iceberg REST v1,
  Apache Iceberg 1.10.1, PyIceberg 0.11.1, DuckDB 1.5.5, and RustFS alpha.81.
- Content-free Iceberg snapshot diagnostics and DuckDB validation of deterministic seed data.
- A bearer-authenticated reference audit collector with transactional deduplication, restrictive
  local permissions, health/metrics endpoints, and a verifiable SHA-256 chain.
- Content-free JSON and Prometheus operational metrics covering tasks, providers, policy,
  approvals, memory, gateways, and audit delivery.
- Executable audit-outage and Postgres recovery drills with checksummed backup manifests,
  explicit restore authorization, and declared reference targets of five-minute RPO and
  fifteen-minute RTO.

## New Commands

```text
loro memory migration-status
loro memory migrate
loro memory reconcile
loro memory snapshots
loro audit metrics
loro audit collect
loro audit collector-verify
loro operations recovery-targets
loro operations backup
loro operations verify-backup
loro operations restore
```

All mutation and restore commands remain dry-run or confirmation gated where applicable. Shared
memory still cannot be committed autonomously by the model.

## Upgrade

```bash
python -m pip install --upgrade "loro-agent==0.6.0"
loro --version
loro config check
loro memory migration-status
loro memory migrate --target 2
```

Review the rendered migration plan before adding `--execute`. Back up managed Postgres first and
follow [Backup, Restore, and Recovery](../recovery.md).

## External Deployment Gates

The public quickstart proves service compatibility, not enterprise authorization. Protected
Polaris CLI/REST denials, delegated credential expiry, production object-store encryption,
immutable audit retention and independent anchoring, corporate identity/policy, and
organization-approved RPO/RTO drills remain deployment-owned evidence. See
[External Enterprise Requirements](../external-enterprise-requirements.md).
