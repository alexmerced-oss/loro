# Loro 0.8.0

Loro `0.8.0` is the enterprise-beta release. It turns the repository's existing governance,
memory, audit, provider, extension, graph, and gateway controls into a reproducible restricted
deployment contract without claiming organization-owned production evidence.

## Highlights

- Added `loro operations benchmark`, a deterministic content-free baseline for configuration
  validation, local-memory retrieval, JSONL audit delivery, and operational-metrics updates.
- Added a pinned reference deployment manifest, restrictive managed policy, synthetic Postgres
  and audit-collector compose stack, and an automated consistency/safety checker.
- Added administrator, operator, security/privacy, pilot-charter, support, installation,
  upgrade, rollback, uninstall, incident, credential-rotation, and offboarding guidance.
- Added scheduled benchmark evidence and release-artifact benchmark/reference-manifest capture.
- Promoted the package and support matrix from alpha to beta while keeping Iceberg memory,
  Polaris, MCP, Agentic Graphs, and remote gateways explicitly experimental until protected
  deployment evidence exists.

## Compatibility

Configuration schema `1.0`, audit schema `1.0`, Postgres shared-memory migrations, provider
contracts, AGS `1.0`, and the advertised MCP revisions are unchanged. Python 3.11 through 3.14
and Linux remain the supported runtime range.

## Upgrade

Back up and verify shared memory, preserve audit backlog and policy digests, install `0.8.0` in a
new virtual environment, run `loro config check --strict`, `loro doctor`, memory migration status,
and the benchmark gate, then exercise a synthetic explicit shared-memory commit and audit
delivery. See the enterprise beta guide for rollback and offboarding.

## External Gates

Corporate identity assertions, signed managed-policy distribution, production TLS/egress,
least-privilege Postgres and Polaris controls, immutable audit retention, provider residency and
retention approval, governed chat applications, owner/on-call assignment, independent testing,
and pilot approval remain adopting-organization responsibilities.
