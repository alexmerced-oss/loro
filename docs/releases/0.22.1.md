# Loro 0.22.1

Unreleased. This page collects changes on the development branch until the release is tagged.

## License metadata

- `src/loro/agraph/UPSTREAM.md` said the Agentic Graph Specification is MIT-licensed. AGS code and
  schemas are Apache-2.0 (the specification text is also available under CC BY 4.0). The bundled
  `agentic-graph` and `oap-profile-authoring` Skills now declare `license: Apache-2.0`, matching
  Loro's `LICENSE`, the `pyproject.toml` `license` field and its classifier, which moved to
  Apache-2.0 after 0.22.0. PyPI still shows MIT for 0.22.0; the next release carries Apache-2.0.

## Managed configuration outranks `--allow-unknown-executors`

- `loro graph validate`, `plan`, `run`, `resume` and `policy explain` turned unknown executor
  extensions on with `--allow-unknown-executors` even when managed configuration set
  `[agraph] allow_unknown_executors = false`. When managed configuration sets the key, its value
  now wins and the flag is ignored with a warning, as with every other managed key. New
  `loro.config.managed_config_data()` and `managed_sets()` expose what managed configuration sets.
