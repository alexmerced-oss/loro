# Loro 0.13.0

Loro `0.13.0` makes setup and everyday interactive use easier, and changes productivity artifact
commands from placeholder scaffolding to governed AI drafting.

## Highlights

- `loro configure` now presents numbered provider, primary-model, and fast-model selections while
  preserving script flags and custom model names.
- Plain `loro` opens a folder REPL. Its ASCII parrot banner is followed by the current folder,
  provider, model, agent, session, and memory state.
- REPL turns retain the durable session ID; `/new`, `/resume`, `/agent`, `/status`, `/help`, and
  `/exit` manage the interaction.
- Document, presentation, spreadsheet, and brief commands ask the configured model for validated
  structured content before rendering files. `loro create docs "..."` is now supported directly.
- Generated content receives artifact DLP checks, spreadsheet formula neutralization, provenance,
  and normal runtime policy, audit, budget, and session handling.

## Compatibility

Existing nested artifact commands and non-interactive configuration flags remain supported.
`--no-ai` retains an explicit offline renderer. The stable 0.10 core and provisional OAP Level 3
classification are unchanged.

## Install

```bash
python -m pip install --upgrade loro-agent==0.13.0
loro configure
loro
```
