# Loro 0.20.0

Release candidate prepared on 2026-09-06.

This release makes WebMCP a first-class governed capability in the CLI and local Web UI. Loro can
discover live page-registered tools from an explicit exact-HTTPS-origin allowlist, isolate browser
state per origin, bind calls to registry revisions, reject stale calls, and close the active page
session. `https://alexmerced.app` remains the bundled default.

The Extensions page now exposes origin management, live schemas, JSON arguments, structured
results, and confirmation for calls that are not explicitly read-only. `loro setup webmcp` writes
reviewable MCP configuration and supports custom origin lists without granting tool authority.
