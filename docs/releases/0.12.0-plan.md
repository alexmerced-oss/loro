# Loro 0.12.0 Release Plan

## Objective

Release the deferred Level 3 harness behavior from 0.11 without expanding Loro's stable-core
promise. The release is complete when composition and every profile-selected runtime capability
are enforced in the live execution path, tested, documented, packaged, and published.

## Delivered Scope

- inheritance composition with cycle/depth rejection and least-privilege layer intersection;
- narrowed MCP server and Agent Skill references;
- explicit bounded subagent delegation;
- profile-selected local/shared memory with identity-tenant scope intersection;
- Agentic Graph profile references through `x-agent-profile`;
- explain, conformance, threat-model, roadmap, release-contract, and release-note updates;
- full unit, security-floor, contract, package, and clean-wheel verification.

## Release Boundary

OAP remains experimental and provisional. The release does not claim formal conformance against
an unavailable canonical upstream revision or fixture suite. The existing 1.0 external evidence,
ownership, controlled-environment, and production gates remain open and unchanged.

## Exit Gates

- repository-wide tests and Ruff lint pass;
- touched files pass Ruff format checks and the package compiles;
- release/evidence inventories, matrices, and generated contract agree;
- coverage remains above the global and security-module floors;
- wheel and source distribution pass Twine and clean-install smoke tests;
- signed tag, GitHub release evidence, and PyPI publication complete, or any external publication
  blocker is recorded precisely.
