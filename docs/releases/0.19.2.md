# Loro 0.19.2

Released on 2026-08-31.

This patch introduces the AAIS 1.0 authority/presenter boundary for protected tools across chats,
delegated work, and graph agents. The Web UI now keeps jobs alive behind a global exact-action
approval modal, and `loro run --approval-stdio` supports independent desktop presenters without
sharing a terminal prompt.
