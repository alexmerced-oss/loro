# Loro 0.17.0

This compatibility release completes Loro's OAP and AGS integrations against the 1.0.1 support packages.

- Uses RFC 8785 canonical JSON for OAP and AGS digests.
- Uses YAML 1.2 boolean semantics while retaining strict duplicate-key checks.
- Delegates AGS semantic validation and run-record schemas to `agentic-graph-spec` 1.0.1.
- Persists, exports, hashes, and updates canonical OAP 1.0 documents while projecting them into
  the runtime model without weakening root-derived trust or policy narrowing.
- Emits canonical `AgentStateDelta` documents and preserves unconsumed canonical fields through
  read/write cycles.
- Retains backward reading support for Loro's pre-1.0.1 profile encoding.
- Makes the CLI wizard, minimal CLI creator, import/export API, and React profile editor author
  canonical OAP 1.0 documents. Browser edits preserve nested skill, MCP, filesystem, lifecycle,
  and state fields the form does not render.
- Maps canonical OAP `network` and `filesystem` requests into Loro's effective permission model;
  the Web UI now labels canonical `max_turns`, lifecycle, reference, and permission fields directly.

Release qualification covers the upstream OAP examples, AGS examples and invalid fixtures,
including AG131 recursive-subgraph detection, plus the complete Loro test suite. Final counts and
release evidence must come from the tagged commit rather than being copied from an earlier run.
