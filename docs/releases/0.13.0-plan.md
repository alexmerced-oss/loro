# Loro 0.13.0 Release Plan

## Objective

Make first-run setup, ongoing folder use, and productivity artifact creation genuinely model
assisted without weakening Loro's policy, audit, session, or data-protection boundaries.

## Delivered Scope

- numbered provider and model selection with an explicit custom-model path;
- plain `loro` and explicit `loro repl` interactive sessions with a parrot banner, folder/model/
  agent/memory metadata, durable session reuse, and session commands;
- governed structured AI drafting for documents, presentations, spreadsheets, and briefs;
- `loro create docs|slides|sheets|brief` aliases and an explicit `--no-ai` offline path;
- generated-content validation, DLP scanning, formula-injection protection, tests, and command
  behavior documentation.

## Exit Gates

- Ruff, repository tests, coverage, security floors, and generated contract checks pass;
- wheel and source distribution pass Twine and clean-environment install smoke tests;
- exact artifact commands populate content from a model draft;
- signed tag, PyPI package, and GitHub release are public.
