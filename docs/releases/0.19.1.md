# Loro 0.19.1

Released on 2026-08-30.

This patch preserves the complete 0.19.0 profile-authoring and portability feature set while
fixing installed-package Skill validation. A bundled Skill may be reached through both the managed
root and an explicit validation path; Loro now deduplicates those references when they resolve to
the same package, while continuing to fail closed when distinct packages declare the same name.

## Validation

- Full Python, Web UI, security, OAP, AGS, MCP, and interoperability suites.
- Installed-wheel validation of the bundled `agentic-graph` Skill.
- Signed-tag release evidence, package build, Twine validation, checksums, SBOM, and provenance.
