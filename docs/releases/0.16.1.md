# Loro 0.16.1

A patch fixing one defect in the Governance view shipped in `0.16.0`.

## Fix

The identity panel reported a fully resolved identity as blank. `IdentityContext` names its fields
`subject` and `tenant`, and the adapter read `actor` and `tenant_id`, so every lookup missed and the
panel rendered "—" for the actor, tenant, and roles. The audit rows directly beneath it carried the
actor correctly, which is what made the discrepancy visible.

Saying who you are resolved as is the panel's entire job, so this made the most prominent card on
the evidence surface useless while looking merely empty rather than broken.

The adapter now reads the field names that exist, and additionally reports the organization and the
authentication method, which were available all along. A regression test asserts the mapping against
an object that deliberately has no `actor` attribute.
