# Loro 0.21.0

Release notes — September 12, 2026.

- Approval decisions made by another local client now wake the issuing run through the durable receipt store. Transactions use a process lock and atomic, flushed writes; corrupt approval state is preserved with a recovery error.
- Stdio decisions validate the AAIS envelope and reviewed action digest. The Web UI keeps keyboard focus inside approval dialogs and shows origin and expiry.
- `loro capabilities --json` reports installed WebMCP prerequisites and explicitly leaves live registry and authorization checks to execution.
- `loro graph recovery RUN_ID` and the matching local Web API report completed nodes, waiting gates, graph drift and uncertain nodes. Resume refuses uncertain effects unless explicitly reviewed through the existing forced-resume approval flow.
- The unused full vendored AGS validator was reduced to its required token and diagnostic interfaces. Canonical validation still uses the AGS support library.

The stable core and experimental support classifications remain unchanged. The report does not automatically restart work or certify that external effects were rolled back.

AGS, OAP and AAIS document/wire formats remain unchanged. Local validation evidence and remaining platform gates are recorded in the ecosystem release report.
